# Learning Rust

I’m learning Rust through *The Rust Programming Language* and [Rustlings](https://github.com/rust-lang/rustlings). This repository is where I keep my exercises and practice as I build a stronger foundation in the language.

## What I’m working on

- Following the concepts and examples in [The Rust Programming Language](https://doc.rust-lang.org/book/).
- Completing Rustlings exercises and keeping my work in the `rustlings/` directory.
- Practicing Rust fundamentals through regular, hands-on coding.

## Getting started

You’ll need a Rust toolchain installed with [rustup](https://www.rust-lang.org/tools/install), as well as the Rustlings command-line tool. From the repository root:

```sh
cd rustlings
rustlings run
```

Rustlings starts the next pending exercise and provides feedback as you work. To check the exercises, run:

```sh
rustlings check-all
```

- [Rustlings](https://github.com/rust-lang/rustlings) — small exercises for learning and practicing Rust.
